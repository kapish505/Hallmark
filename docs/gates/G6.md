# G6 TEE feasibility (add-on A5): NOT RUN, private route NOT SHIPPED

Needs a TEE host the team can actually access (a confidential VM with Intel TDX or AMD SEV-SNP, an NVIDIA H100 in
confidential-computing mode, or a TEE inference service; none verified). Pass requires **all** of:

1. A real TEE host, with what it costs recorded.
2. The enclave generates a keypair and returns an attestation quote whose report data binds the public key hash. An
   independent verifier script on a laptop checks the quote chain and prints the measurement.

No TEE host was available while building, so nothing was attempted and **no attestation is faked**. Following the add-on's
fail rule: the private route is dropped, the README says so, and A1 to A3 ship. Edge cases 32 to 34 and 37 belong to the
private route and are not implemented.
