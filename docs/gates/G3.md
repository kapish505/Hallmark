# G3 Determinism and separation: NOT RUN

The gate that sets every parameter. Build both worker images, pin them by digest, run them on **at least 2 machines with
the same digest**, then:

```bash
pnpm calibrate --task asr --data data/g3/asr --workers http://m1:9000,http://m2:9000 --runs 20 --honest-cost-tinybar <estimate> --digest sha256:...
pnpm calibrate --task ocr --data data/g3/ocr --workers http://m1:9001,http://m2:9001 --runs 20 --honest-cost-tinybar <estimate> --digest sha256:...
```

Data: ASR at least 8 clips of 8-15 s (clean and noisy, ASCII transcripts, no ambiguous numbers), canonical 16 kHz mono WAV.
OCR at least 8 PNGs with at most 96 words of ASCII text (receipts, signs, screenshots, one rotated or noisy). Every input
gets a human-checked `<name>.ref.txt` (add-on A2). Record each clip's source and licence.

Decided before G3 (add-on A3): OCR uses **NORM_OCR_V1B** (keeps `.` and `,` between digits), so calibration uses the final normalization.

Output: `docs/gates/G3.asr.json`, `G3.ocr.json` (class, tau, fp, per-cheat pi and c', accuracy). Copy the values into the
`hallmark-measurements` block of `docs/MEASUREMENTS.md` (source `measured`) and into `docs/ACCURACY.md`.
Rule: EXACT only if every honest comparison (at least 200) agrees bit for bit; otherwise TOLERANCE with the smallest tau giving
fp <= 0.5%; if no tau gives fp <= 1% with the worst cheat's pi >= 0.3, the task is **not coverable** on this stack.
